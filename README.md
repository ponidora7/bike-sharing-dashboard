# 🚲 Bike Sharing Dashboard

Dashboard analisis data penyewaan sepeda (Bike Sharing Dataset 2011-2012).

## 📊 Fitur Dashboard

- **Analisis Pola per Jam**: Visualisasi pola sewa registered vs casual per jam
- **Analisis Dampak Cuaca**: Perbandingan volume sewa saat cerah vs hujan/salju
- **Filter Interaktif**: Filter data berdasarkan tahun (2011/2012)
- **Ekspor Data**: Download data terfilter dalam format CSV

## 🛠️ Teknologi

- Python 3.x
- Streamlit
- Pandas
- Matplotlib
- NumPy
